# 词流 Lexicon Flow

纯前端英语词汇记忆系统：完整 CET-4/CET-6 词库、双线训练模型、无框架无后端，直接用浏览器打开即可离线使用。

本项目包含两个版本，数据、逻辑与功能完全一致，仅 UI 视觉不同：

| 目录 | 说明 | 入口 |
|---|---|---|
| `functional/` | 功能更新版（默认清新绿主题） | `functional/standalone.html` |
| `ios/` | iOS 风格响应式副本（默认 iOS 蓝主题） | `ios/standalone.html` |
| `docs/` | 交付说明书（v2 / v2.1 / v3.0 更新记录） | `docs/交付说明书.txt` |

## 核心功能

- **输入线（被动词汇）**：受控输入 + 语境复现 + 间隔重复。6574 词带多语境例句，复习是在新语境中再次偶遇目标词；接触 ≥3 语境、连对 ≥2 轮、掌握分 ≥60 → 解锁产出线。
- **产出线（主动词汇）**：强制产出 + 四级阶梯（首字母填空 → 同义替换 → 多解挖空 → 独立造句）。产出失败自动回炉输入线，形成「识别稳定 → 强制产出 → 失败回炉」循环。
- **词库**：6667 条 CET-4/CET-6 词条，含词性、释义、搭配、例句译文、同近义词（点击跳转）；支持批量管理、快速添加、双主题换肤、TTS、错题本、完整备份导出。
- **答题反馈**：答对词框变绿；答错词框变红并在下方另起「正确答案」词框。

详细使用说明见各版本目录下的 `README.md`。

## 快速开始

直接用浏览器打开对应版本的 `standalone.html`（单文件，已内联全部 CSS/JS）。开发模式可打开 `index.html`，或在版本目录执行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`。

## 数据与隐私

学习进度保存在浏览器 localStorage，内置词库常驻内存；无账号、无运行时网络请求。更换浏览器或清理数据前请导出备份。词库数据来自第三方开源词表 kajweb/dict（有道背单词导出数据），分发时请遵守其上游授权要求。
