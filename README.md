# 词流 Lexicon Flow

移动端优先的英语词汇记忆系统。纯 HTML + CSS + JavaScript，无框架、无后端、无外部资源依赖；直接双击 `standalone.html` 即可离线使用。

## 双线训练模型（v3）

- **输入线（被动词汇）**：受控输入 + 语境复现 + 间隔重复。6574 词带多语境例句，复习是"在新材料中再次偶遇目标词"，而非闪卡选义。稳定识别门槛：≥3 个语境接触 + 连对 ≥2 轮 + 掌握分 ≥60 → 解锁主动线。
- **产出线（主动词汇）**：强制产出 + 四级阶梯（首字母填空 → 同义替换 → 多解挖空 → 独立造句）。产出失败自动回炉输入线，形成"识别稳定 → 强制产出 → 失败回炉"循环。
- **答题反馈**：答对词框变绿；答错词框变红并在下方另起"正确答案"词框。
- **词库**：完整 CET-4/CET-6 共 6667 词，含词性、释义、搭配、例句译文与同近义词（点击可跳转）；支持双主题换肤、批量管理、快速添加、TTS、响应式布局（手机 / 平板 / PC）。

## 目录结构

| 路径 | 说明 |
|---|---|
| `functional/` | 功能更新版（默认清新绿主题），入口 `functional/standalone.html` |
| `ios/` | iOS 风格响应式副本（默认 iOS 蓝主题），入口 `ios/standalone.html` |
| `docs/交付说明书.txt` | 完整功能说明、重构记录与验证结果 |

两个版本数据与业务逻辑完全一致，仅 UI 视觉不同。各自的 `README.md` 含详细使用说明。

## 快速开始

1. 直接打开对应版本的 `standalone.html`（单文件，已内联全部 CSS/JS）。
2. 开发模式：在该版本目录执行 `python3 -m http.server 8080`，浏览器访问 `http://localhost:8080`。
3. 重建单文件：`node build-standalone.mjs`（内含语法完整性校验）。
4. 端到端测试：`node tools/e2e-test.cjs <版本目录绝对路径>`（需 jsdom）。

## 数据与隐私

学习进度仅保存在浏览器 localStorage，内置词库常驻内存；无账号、无网络请求（AI 功能需用户自行配置接口）。更换浏览器或清理数据前请在"我的"页面导出备份。
