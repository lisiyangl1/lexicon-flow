二、修复：应用无法正常打开
-------------------------------------
根因：上一版打包脚本 build-standalone.mjs 使用字符串作为
String.replace 的替换值，app.js 源码中的正则转义文本 "\\$&"
里的 $& 被替换引擎解析为"整个匹配项"，导致内联进
standalone.html 的 app.js 被截断损坏——单文件版打不开。
（模块化 index.html 版不受影响。）

修复与加固：
- 所有 replace 改用函数替换器（返回值不解析 $ 模式）；
- 打包后自动对每段内联脚本执行 node --check 语法校验，
  损坏会直接报错而不是产出坏文件。

加载。新版架构：
- 词库常驻内存（words.js），不占 localStorage；
- localStorage 只存：学习进度覆盖（仅变化的词）、个人词汇、
  日志、设置 —— 日常仅几 KB；
- 内置词使用稳定 ID（b_单词），进度跨版本可迁移；
- 旧版 v1 数据首次启动自动迁移（按单词文本匹配），
  学习进度、个人词汇、每日目标都会保留。

根因：applyTheme 只修改了 html 的 data-theme 属性，没有同步
切换两套样式表（styles.css / theme-ios.css）的启用状态，
导致属性变了、CSS 纹丝不动。

验证：jsdom + Edge 双重确认样式表 disabled 状态与 data-theme
同步翻转；iOS 副本默认主题（iOS 蓝）亦恢复正常。

十二、词库管理重构（告别逐个操作）
-------------------------------------
1. 批量管理（词库页 → 批量管理按钮）：
   - 进入勾选模式，点击词条即勾选，支持全选/取消全选；
   - 底部操作栏：入候选池 / 回被动库 / 清错题 / 删个人词；
   - 删除仅对个人词汇生效，内置词受保护；

   - 可选目标词库：被动词汇库 / 转化候选池 / 主动词汇库；

   - 需要完整字段（音标/例句/搭配）仍走「我的 → 批量导入词汇」。

十三、答题反馈 UI 优化
-------------------------------------
- 答对：词框变绿（绿边框 + 浅绿底 + 光晕，翻卡动画）。
- 答错：词框变红（红边框 + 浅红底 + 震动动画），并在词卡

  音标、词性、释义与语境例句及译文，弹入动画呈现。

十四、被动/主动词汇双线分开设计（v3 核心）
-------------------------------------
【输入线 · 被动词汇】受控输入 + 语境复现 + 间隔重复
- 词库重建：6574 词带语境例句（共 1.4 万+ 条），4649 词
  拥有 2 条以上不同语境（words.js 第 11 列 contexts）。
- 三种识别任务轮换：语境选义 / 语境判断 / 听音识义；
  目标词在句中高亮（ctx-mark），每题优先选未接触过的新语境。
- 题面徽标：语境序号、累计接触次数、已知词覆盖率。
- 答对一次 = 一次有效语境接触（exposures+1），
  同时仍按五档间隔重复安排复习。
- 稳定识别门槛：接触≥3 语境 且 连对≥2 且 掌握分≥60
  → 自动解锁主动线（toast 提示，详情页可手动解锁）。

【产出线 · 主动词汇】强制产出 + 四级阶梯
- L1 语境+首字母填空 → L2 同义替换（无同义词自动降级 L1）
  → L3 语境挖空+中文释义（目标词与同词性库内同义词多解判对）
  → L4 独立造句（≥6 词且含目标词）→ 通关后巩固维护（多解挖空）。
- 产出失败（或输入线复查主动词答错）→ 自动回炉输入线：
  level=passive、掌握分减半、回炉次数+1，
  在更多语境中重新积累后再度尝试解锁。
- 形成「识别稳定 → 强制产出 → 失败回炉」循环。
