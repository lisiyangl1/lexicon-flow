# 词流 Lexicon Flow（功能更新版 · v3 双线训练）

纯前端英语词汇记忆系统：无框架、无后端、无运行时网络依赖，直接用浏览器打开即可使用。当前版本以「输入线（被动词汇）」与「产出线（主动词汇）」两条独立线路组织训练。

> 仓库中另一份 `vocab-flow-ios/` 是同数据、同逻辑、仅 UI 视觉不同的 iOS 风格副本；两份目录各自可使用。

## 1. 项目背景与解决的问题

常见英语词汇学习的问题：词库不全、词条缺少词性/搭配/例句；复习停留在「看词选义」的闪卡，认识的词无法转化为会用的词；被动词汇与主动词汇混在一条流程里，无法区分「识别稳定」和「能主动产出」。

本项目的应对（均可在源码中验证）：

| 问题 | 本项目的实现 |
|---|---|
| 词汇数据不全 | 内置 6667 条 CET-4/CET-6 词条（`words.js`），含词性、释义、搭配、例句译文、同近义词 |
| 闪卡式识别不真实 | 输入线在**不同语境例句中再次偶遇**目标词，而非单纯看词选义 |
| 识别与产出混淆 | 拆为输入线 / 产出线；只有满足稳定识别门槛的词才解锁产出线 |
| 产出失败无反馈闭环 | 产出失败自动回炉输入线，在更多语境中重新积累后再解锁 |
| 逐词管理效率低 | 批量管理 + 快速添加（多行粘贴） |
| 学习进度易丢 | localStorage 仅存进度覆盖、个人词、日志与设置；支持完整备份导出 |

## 2. 主要功能与适用场景

### 2.1 双线训练模型（v3 核心）

**输入线（被动词汇）**：受控输入 + 语境复现 + 间隔重复。

- 三种任务轮换：语境选义 / 语境判断 / 听音识义；目标词在句中高亮，题面显示语境编号、累计接触次数、已知词覆盖率。
- 优先选取**未接触过**的语境例句（`store.js` 的 `seenContexts`）。
- 答对一次记一次有效语境接触（`exposures + 1`），并按五档 SRS 排下次复习。
- 稳定识别门槛：`exposures ≥ 3` 且 `streak ≥ 2` 且 `mastery ≥ 60` → 自动解锁产出线（常量见 `store.js`）。

**产出线（主动词汇）**：强制产出 + 四级阶梯。

| 阶梯 | 任务 | 通过条件（见 `app.js` 的 `submitAnswer`） |
|---|---|---|
| L1 | 语境 + 首字母填空 | 输入等于目标词 |
| L2 | 同义替换 | 输入等于目标词；无同义词时自动降级为 L1 |
| L3 | 语境挖空 + 中文释义 | 输入为目标词或词库内同词性同义词（多解） |
| L4 | 独立造句 | 句子含目标词且英文单词数 ≥ 6 |
| 通关后 | 巩固维护 | 多解挖空（维持产出，`conversionStep` 保持 4） |

- 产出失败或输入线复查主动词答错 → 回炉：降回输入线、`mastery` 减半、`prodFails + 1`。

**答题 UI 反馈**：答对词框变绿；答错词框变红，并在词框下方另起「正确答案」卡片（单词、音标、词性、释义、语境例句）。

### 2.2 词库数据（以 `words.js` 实际统计为准）

| 指标 | 数值 |
|---|---|
| 总词条 | 6667（按 `exam` 字段：CET4 4528 / CET6 2139，两类互斥） |
| 含音标 | 6638 |
| 含同近义词 | 6191（92.9%） |
| 含主例句 | 6579；附中文译文 6500 |
| 含多语境例句 | 6574 词、共 14304 条语境，其中 4649 词有 ≥2 条语境 |
| 含搭配 | 5112 |
| 难度分布 | 简单 1873 / 中等 2671 / 困难 2123（CET4∩CET6 → 简单，仅 CET4 → 中等，仅 CET6 → 困难） |

`words.js` 每行 11 列：`[单词, 音标, 词性, 释义, 搭配(|分隔), 例句, 例句译文, 难度, 分类, 同义词(|分隔), 语境材料]`。语境材料内部以 `\u0001` 分隔句子与译文、以 `\u0002` 分隔多条语境（`data.js` 的 `parseContexts`）。

### 2.3 其他功能

- 五页应用：首页（今日进度与训练入口）、词库（输入线/产出线两栏 + 搜索筛选 + 批量管理）、复习（会话与滑动手势）、统计（双线卡片、阶梯分布、本周解锁/回炉、7 日趋势）、我的（偏好、导入导出、备份、AI 配置）。
- 双主题：清新绿（本项目默认）/ iOS 蓝（副本默认），通过启停样式表真实切换并持久化。
- TTS 朗读（`speechSynthesis`）、同义词点击跳转详情、错题本、完整备份导出/恢复初始词库。
- AI 拓展：兼容 OpenAI Chat Completions 的接口配置；**默认不发送任何网络请求**，仅在主动使用 AI 功能时调用。

### 2.4 适用场景

- CET-4 / CET-6 备考：按词库分类筛选与训练。
- 已有一定识别量、想把「认识的词」转为「会用的词」的学习者：走解锁 → 四级产出 → 失败回炉流程。
- 离线 / 移动端学习：`standalone.html` 单文件可直接打开，不依赖网络。

## 3. 安装方法与环境依赖

### 3.1 运行应用（无需安装）

| 方式 | 操作 | 说明 |
|---|---|---|
| 单文件 | 用浏览器打开 `standalone.html` | 已内联 CSS 与全部 JS，可复制到手机离线使用 |
| 开发模式 | 用浏览器打开 `index.html` | 需保持同目录 `.css` / `.js` 文件完整 |
| 本地服务（可选） | 在本目录执行 `python3 -m http.server 8080`，访问 `http://localhost:8080` | 手机同 Wi-Fi 可用 `http://<电脑局域网IP>:8080` |

浏览器需支持 ES2020+、localStorage；TTS 依赖系统语音合成（`speechSynthesis`）。

**无 `package.json`、无 npm 安装步骤、无后端服务。** 数据按浏览器与站点来源隔离：`file://` 与 `http://` 是不同存储来源，切换后需重新导出/导入备份。

### 3.2 开发工具依赖

| 工具 | 依赖 | 备注 |
|---|---|---|
| `build-standalone.mjs` | Node.js（使用 ESM、`node --check`） | 无第三方包 |
| `tools/build-dict.mjs` | Node.js + 外部 NDJSON 原始数据 | **原始数据不在项目内**（见第 7 节） |
| `tools/merge-extras.mjs` | Node.js | 依赖同目录 `extras.json` |
| `tools/e2e-test.cjs` | Node.js + jsdom | jsdom 需可解析（见第 7 节） |

## 4. 使用方法和常用命令

### 4.1 界面操作路径

1. 打开 `standalone.html` → 首页点「输入线 · 语境识别」开始语境偶遇训练；答完选择掌握程度评分。
2. 输入线解锁后，首页点「产出线 · 强制产出」，按当前阶梯完成首字母填空 / 同义替换 / 挖空 / 造句。
3. 词库页：切换「输入线 / 产出线」标签；「＋ 快速添加」多行加词；「批量管理」中勾选后可解锁主动线、回输入线、清错题、删个人词。
4. 我的页：学习目标、发音语速、批量导入、导出完整备份、AI 接口配置。
5. 顶部调色板按钮切换主题；词汇详情页可点击同义词跳转、手动解锁主动线（掌握分 ≥60）。

### 4.2 常用命令

以下命令均需**先进入项目目录**（脚本使用相对路径读写文件）：

```bash
# 先进入项目目录（脚本使用相对路径读写文件）
cd <项目目录>

# 重新打包单文件（内联 CSS/JS，并逐段语法校验）
node build-standalone.mjs

# 端到端测试（默认测试当前目录；jsdom 需可解析，见第 7 节）
node tools/e2e-test.cjs
# 或指定版本目录：node tools/e2e-test.cjs <版本目录路径>

# 从 NDJSON 原始数据重建词库（原始数据需另行准备）
node tools/build-dict.mjs <NDJSON目录> words.js

# 重建后合并手工补充词并修正 misled 词条
node tools/merge-extras.mjs
```

### 4.3 导入格式

**批量导入**（我的 → 批量导入词汇）：支持 JSON 数组、`{"words":[...]}` 或逐行文本。逐行文本若含 `|` 则用 `|` 分隔，否则用 `,` 分隔；9 列为 `单词 | 音标 | 词性 | 释义 | 搭配 | 英文例句 | 例句译文 | 难度 | 分类`。缺少单词或释义的行报错，`#` 开头行跳过，重复单词跳过。

**快速添加**（词库页 → ＋ 快速添加）：每行 `单词 | 中文释义`，选择加入输入线（默认）或产出线；重复词跳过，释义必填。

**备份导出**：我的 → 导出完整备份，生成 `lexicon-flow-backup-YYYY-MM-DD.json`，内容为 `{version:2, progress, userWords, logs, settings, createdAt, exportedAt}`。

## 5. 输入与输出示例

### 5.1 快速添加（输入 → 界面结果）

输入（词库页 → ＋ 快速添加，目标选「输入线」）：

```text
serendipity | 意外发现美好事物的运气
bucket list | 人生愿望清单
```

输出（界面提示）：`成功添加 2 条。` 新词出现在词库「输入线」标签下，标记为个人词、掌握分 0，首次复习到期。

若再粘贴一次同样两行：`成功添加 0 条，跳过已在词库的 2 条。`

### 5.2 批量导入（输入 → 输出）

输入（我的 → 批量导入词汇）：

```text
ability | /əˈbɪlɪtɪ/ | n. | 能力 | innovation ability;learning ability | The test measures your mathematical ability. | 这种测试考查的是数学能力。 | 中等 | custom
# 这是注释行，会被跳过
```

输出（界面提示）：`成功导入 1 条，跳过 0 条。`

JSON 数组形式同样可用，例如 `[{"word":"myword","meaning":"我的词"}]`，输出格式一致。

### 5.3 训练界面（输入 → 输出）

输入线「语境选义」题面输出示例：

```text
语境选义 · 输入线
语境 1/3   已接触 1 次   已知词覆盖 75%
The test measures your mathematical ability.
这种测试考查的是数学能力。
[选项列表]  ← 点击一个释义
```

答错后的输出：词框变红，并在下方新增答案框：

```text
正确答案  ability  /əˈbɪlɪtɪ/ · n.
能力；能耐，本领
The test measures your mathematical ability.
这种测试考查的是数学能力。
```

产出线 L1「语境首字母填空」题面输出示例（目标词 `myoldword`）：

```text
阶梯一 · 语境首字母填空 · 阶梯 1/4
[语境句子挖空：______]
M·________     我的旧词
[输入框]  ← 输入 myoldword 后点「确认答案」
```

答对输出：`回答正确` + 绿框；答错输出：`需要再巩固` + 红框 + 答案框，并提示「产出失败：该词已回炉输入线……」。

## 6. 文件结构

| 文件 | 职责 |
|---|---|
| `index.html` | 页面骨架、五栏导航、双主题样式表与引导脚本 |
| `words.js` | 6667 条词库数据 + 多语境例句（自动生成，勿手改） |
| `data.js` | 词行规范化、稳定 ID（`b_单词`）、语境解析、同义词查找 |
| `srs.js` | 五档间隔重复纯函数、到期判断 |
| `store.js` | localStorage 存储（key `lexicon-flow:v2`）、双线状态机、CRUD、导入导出、统计 |
| `ai.js` | OpenAI 兼容接口封装（可选） |
| `app.js` | 路由、页面渲染、双线会话状态机、TTS、手势、主题切换 |
| `styles.css` / `theme-ios.css` | 清新绿 / iOS 蓝主题 |
| `standalone.html` | 生成物：可直接打开的单文件版本 |
| `build-standalone.mjs` | 单文件打包 + 内联脚本语法校验 |
| `tools/build-dict.mjs` | 从 NDJSON 重建 `words.js`（含多语境提取） |
| `tools/merge-extras.mjs` / `tools/extras.json` | 重建后合并 5 个手工补充词并修正 `misled` |
| `tools/e2e-test.cjs` | jsdom 端到端测试 |

## 7. 已知限制与数据说明

- **词库原始数据不在项目内**：`tools/build-dict.mjs` 需要 `CET4_*.json` / `CET6_*.json` 格式的 NDJSON，需通过第一个参数显式传入数据目录。缺少这些文件时无法从零重建 `words.js`；正常使用时无需重建，直接使用已生成的 `words.js` 即可。
- **测试脚本依赖 jsdom**：`tools/e2e-test.cjs` 按「项目本地安装的 jsdom → `JSDOM_PATH` 环境变量指向的 node_modules 目录」顺序解析 jsdom；未安装时给出明确提示并退出。第一个参数可指定待测试的版本目录，省略时测试当前目录。
- **构建脚本需在项目目录内运行**：`build-standalone.mjs` 用相对路径读取 `index.html`、CSS 与 JS，输出 `standalone.html`。
- **存储隔离**：进度保存在 localStorage，`file://` 与 `http://` 互不共享；清理浏览器数据前须导出备份。
- **AI 功能为可选**：未配置接口时所有功能仍可离线使用；配置后密钥保存在本机前端，公开部署建议使用服务端代理。
- **音标/释义来自上游数据源**：个别词条字段可能缺失（含音标 6638/6667、含同义词 6191/6667），属数据本身限制，应用不虚构补全。
