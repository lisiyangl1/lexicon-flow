# 词流 Lexicon Flow（iOS 风格响应式副本 · v3 双线训练）

移动端优先的英语词汇记忆系统。纯 HTML + CSS + JavaScript，无框架、无后端、无外部资源依赖。支持响应式布局：手机竖屏、平板与 PC（≥900px 自动切换侧边导航与多列布局）。

## 1. 立即使用

- **最简单**：把整个文件夹复制到手机，使用浏览器打开 `standalone.html`。这是已打包全部 CSS 和 JavaScript 的单文件版本。
- **开发与二次修改**：打开 `index.html`，保持同目录下的 `.css`、`.js` 文件完整。
- **本地预览服务**：在本目录执行 `python3 -m http.server 8080`，访问 `http://localhost:8080`；同一 Wi-Fi 下手机访问 `http://电脑局域网IP:8080`。

也可以部署到 GitHub Pages、Cloudflare Pages、Netlify、Vercel 或任意静态网站空间，无需构建命令，发布目录选择本项目目录即可。

> 数据跟随浏览器与站点来源保存。直接打开文件和通过 HTTP 打开属于不同存储来源；清理浏览器数据前请先导出备份。

## 2. 内置词库（完整四六级 + 多语境材料）

- **6667 条完整词汇：CET-4 4528 条、CET-6 2139 条**（来源：kajweb/dict，有道背单词数据，`tools/build-dict.mjs` 生成）。
- 每条包含：单词、音标、词性、中文释义、高频搭配（常见用法）、英文例句及中文翻译。
- **多语境例句**：6574 词带语境例句（共 1.4 万+ 条），其中 4649 词拥有 2 条以上不同语境——这是输入线"语境复现"的数据基础。
- **同近义词**：93% 以上词条附带同近义词，在词汇详情页以标签展示；点击同义词可直接跳转到对应单词的详情界面（词库外的同义词以灰色展示、不可点击）。
- 难度标签：CET4∩CET6 → 简单；仅 CET4 → 中等；仅 CET6 → 困难。

### 存储架构（v2）

内置词库常驻内存（words.js），**localStorage 只保存学习进度、个人词汇、日志和设置**（通常仅几 KB），不会因词库增大而撑爆存储。旧版 v1 数据首次启动时自动迁移（按单词文本匹配进度，旧"转化候选"词自动归入产出线），无需手动处理。

## 3. 双线训练模型（v3 核心）

被动词汇与主动词汇**分开设计、各走一条线**：

### 输入线（被动词汇）—— 受控输入 + 语境复现 + 间隔重复

- 复习不是"看词选义"，而是**在新语境中再次偶遇目标词**：语境选义、语境判断、听音识义三种任务轮换。
- 每道语境题优先选取**没有接触过的例句**，同一次接触只计一次；题面显示语境编号、累计接触次数与已知词覆盖率徽标。
- 每答对一次记一次有效语境接触（exposures+1），仍按五档间隔重复安排下次复习。
- **稳定识别门槛**：接触 ≥3 个语境 且 连续识别 ≥2 轮 且 掌握分 ≥60 → 自动解锁主动线。

### 产出线（主动词汇）—— 强制产出 + 四级阶梯

| 阶梯 | 任务 | 说明 |
|---|---|---|
| L1 | 语境 + 首字母填空 | 有线索的受控产出 |
| L2 | 同义替换 | 给出同义词线索，写出目标词（无同义词自动降级 L1） |
| L3 | 语境挖空 + 中文释义 | 挖空填词，目标词与同词性词库内同义词均判对（多解） |
| L4 | 独立造句 | 看中文释义写完整句子（≥6 词且含目标词） |
| 通关后 | 巩固维护 | 继续以多解挖空维持产出 |

- **失败回炉**：产出失败（或输入线复查主动词答错）→ 自动降回输入线，掌握分减半、回炉次数 +1，在更多语境中重新积累后再度尝试解锁。
- 形成 **"识别稳定 → 强制产出 → 失败回炉"** 的完整循环。

### 答题反馈（UI）

- **答对**：词框变绿（绿框 + 浅绿底）。
- **答错**：词框变红，并在下方**另起一块"正确答案"词框**，展示单词、音标、词性、释义与语境例句。

## 4. 主题换肤

顶部标题栏右侧 **调色板按钮**，点击即可在两套主题间自由切换（样式表真实启用/停用），选择会持久保存：

| 主题 | 说明 |
|---|---|
| 清新绿（默认） | 护眼绿配色、柔和卡片，长时间背单词舒适 |
| iOS 蓝 | iOS 设计语言：SF 字体、系统色板、毛玻璃导航、连续圆角、弹性动画 |

两套主题通过 `styles.css` / `theme-ios.css` 实现，切换时禁用其一，功能完全一致。iOS 风格副本（vocab-flow-ios）默认启用 iOS 蓝。

## 5. 词库批量管理与快速添加

词库页分**输入线 / 产出线**两个标签页，配工具栏：

**批量管理**：点击「批量管理」进入勾选模式，底部操作栏支持：
- **解锁主动线**：掌握分 ≥60 的输入线词一键解锁（不足 60 自动跳过并提示）
- **回输入线**：把产出线词批量打回输入线
- **清错题 / 删个人词**：批量移出错题本、批量删除个人词汇（内置词受保护）
- 切换等级标签或筛选条件会自动清空勾选，避免误操作

**快速添加**：每行一条粘贴 `单词 | 中文释义`（释义必填），选择加入输入线（推荐）或产出线后一次性入库；重复词自动跳过。完整字段导入仍走「我的 → 批量导入词汇」。

## 6. 页面与统计

| 页面 | 功能 |
|---|---|
| 首页 | 今日到期、稳定识别数、语境接触总数、双线训练入口 |
| 词库 | 输入线/产出线两栏，搜索及难度、掌握度、分类筛选 |
| 复习 | 输入线语境识别、产出线四级阶梯、错题重练、TTS 与滑动卡片 |
| 统计 | 双线卡片、产出阶梯分布（L1–L4）、本周解锁/回炉、近 7 日趋势 |
| 我的 | 学习目标、发音语速、批量导入、完整备份、AI 接口配置 |

词汇详情页新增**双线学习状态**：当前线路、语境接触次数、阶梯进度、历史回炉次数；掌握分 ≥60 时可手动「解锁主动线」。

## 7. 批量导入格式

支持 JSON 数组、包含 `words` 数组的 JSON 备份，以及逐行文本。重复单词自动跳过。

```text
单词 | 音标 | 词性 | 释义 | 搭配1;搭配2 | 英文例句 | 例句译文 | 难度 | 分类
ability | /əˈbɪləti/ | n. | 能力 | have the ability to | This ability improves with practice. | 这种能力会随练习提高。 | 中等 | custom
```

## 8. 代码模块说明

| 文件 | 职责 |
|---|---|
| `index.html` | 页面骨架、五栏导航、双主题样式表加载、主题引导脚本 |
| `words.js` | **6667 条完整四六级词库数据 + 多语境例句**（自动生成，请勿手改） |
| `data.js` | 词库规范化、稳定 ID、语境解析、双线字段、同义词查找 |
| `srs.js` | 五档间隔重复纯函数、到期判断 |
| `store.js` | v3 存储：双线状态机（解锁/阶梯/回炉）、CRUD、导入导出、统计 |
| `styles.css` | 清新绿主题（移动设计 + 平板/PC 响应式布局） |
| `theme-ios.css` | iOS 蓝主题（同一套选择器，不同视觉变量） |
| `ai.js` | OpenAI 兼容接口封装 |
| `app.js` | 单页路由、双线训练状态机、语境材料渲染、TTS、手势、主题切换 |
| `build-standalone.mjs` | 单文件打包脚本（含语法完整性校验）：`node build-standalone.mjs` |
| `tools/build-dict.mjs` | 词库生成脚本（含多语境提取） |
| `tools/merge-extras.mjs` | 重建词库后合并手工补充词（bolster/deplete/dwindle/exacerbate/mitigate） |
| `tools/e2e-test.cjs` | 端到端测试（jsdom）：迁移/换肤/同义词/解锁门槛/阶梯回炉/UI 反馈 |

## 9. 间隔重复规则

| 自评 | 掌握分变化 | 下次复习 |
|---|---|---|
| 完全不会 | 明显降低 | 10 分钟后，当日重测 |
| 有点印象 | 向 25 分靠拢 | 1 天 |
| 基本掌握 | 向 50 分靠拢 | 3 天 |
| 熟练 | 向 75 分靠拢 | 7 天 |
| 非常熟练 | 向 92 分靠拢 | 15 天；连续熟练后 30 天 |

所有答错词自动进入错题本，之后答对会自动清除错题标记。

## 10. AI 拓展与使用提示

- 默认不发送任何网络请求。在「我的 → AI 拓展配置」中可填写 OpenAI Chat Completions 兼容服务配置。
- 顶部调色板按钮可随时切换主题；详情页可点击同义词跳转。
- 首次从旧版本升级会自动迁移学习进度；如需彻底重置，在「我的 → 恢复初始词库」。
- TTS 依赖系统语音：iOS 推荐 Safari，Android 推荐 Chrome。
- 定期在「我的」页面导出备份；更换浏览器或清除数据前务必先备份。
